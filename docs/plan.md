## スケジュール

### 8/12–8/15 — 実機で実寸を出し切る

最優先。ここが出来ないと他が全部無意味になります。

- [ ] `calibrate.py` → `make_board.py` → 印刷 → 実測 → `calibrate_metric.py`
- [ ] `--verify` で定規チェック。**残差 2mm 以下**に追い込む
- [ ] `--check` で投影範囲を確認。**900 × 500mm 取れているか**（φ270mm の皿とメニューが同居する）
- [ ] `config.json` の `table_sign.serving_center_mm` を実際の提供位置に合わせる
- [ ] 超短焦点の影の出方を確認（アームがどこに立つと影が皿にかかるか実測）

較正がどうしても合わない場合の切り分け順: ボードのたわみ → カメラのピンぼけ →
`calibration.json` のズレ（カメラかプロジェクターを動かしていないか）。

### 8/15–8/16 — 指差しを実機で詰める

ロジックはテスト済みなので、ここで見るのは**認識と視差**だけです。

- [ ] `uv run python src/fetch_model.py` でモデル取得
- [ ] `--pointer hand` + `d` キーで、指先の照準が実際の指とどれだけずれるか実測
- [ ] 系統的なズレがあれば `pointer.offset_mm` で打ち消す
- [ ] 投影光が手に乗った状態でも検出が保つか確認（暗い店内を想定して照明を落として試す）
- [ ] 的の大きさ（`dish_tile_mm` / `size_button_mm`）を、実際に指してみて調整

**机に触れて指す**運用にすること。浮かせると視差でずれます。

## リスクと対処

| リスク | 対処 |
|---|---|
| プリンタの縮尺ずれで実寸がずれる | `--measured-marker-mm` で補正。手順を README に明記済み |
| アームが間に合わない | Tier 1 単独で提出（設計上、成立する） |
| 本番でアームが食器を落とす | 撮影は複数テイク。`--arm mock` でリハーサルを分離 |
| 投影にアームの影が入る | 8/15までに影の位置を実測し、RETREAT 姿勢を影が皿にかからない位置に |
| 指差しの精度が出ない | 的を大きくする → `offset_mm` で補正 → それでも駄目ならキーボード操作で撮影（`--pointer none`） |
| 投影範囲が狭くて皿が収まらない | プロジェクターを離す。皿は実寸から縮められない |
| 準決勝の投票が伸びない | 冒頭5秒に全振り。SNS 用に15秒の縦型も切り出す |
